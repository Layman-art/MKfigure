# 生成与改图

## 首次生成

已有资料先读，不要求用户复述。论文中的方法、条件、变量和流程关系应有页码/式号依据。风格参考只提取版式、插画复杂度、信息密度、比例和配色，不照搬其中的数字或方法；素材库先查看代表性文件并记录复用来源。

提示词保留用途、语言、比例、经核实的内容、模块及有向关系、精确文案、视觉要求和禁止添加的内容。用户已写好提示词时可直接使用，AI 整理为可选步骤。图像模型的字体提示只是意图，精确字体在可编辑层落实。

```text
用途：[论文方法图/机制图]；[语言]；[画幅/使用宽度]
内容与关系：[已核实的模块、变量和箭头]
文字（逐字）：[标签与公式]
视觉：[所选参考的布局、密度和插画要求，或用户描述]
字体意图：中文微软雅黑；英文 Times New Roman；数学变量衬线斜体
限制：不增添结果数字、虚构曲线或改变变量和箭头含义
```

无参考时按文字直接生成：默认白底、深色文字、有限且有语义的配色，颜色搭配线型或标签区分。可选深蓝、青绿和暖橙，不固定套用卡片网格。用户已有参考时保留其视觉复杂度，不为后续矢量化削弱插画和层次。

## 首图不满意

两种入口均不自动带入旧风格参考图或风格提示词，用户明确要求沿用时才加入。用户选择明确则直接执行，不重复询问。

1. **直接提示词**：不强制先让 AI 重写。用户可选择“带当前图修改”，把原图加修改提示词交给图像编辑能力；也可选择“不带原图重生成”，仅按这次提示词重新生成，不偷偷附原图。若用户只提出局部修改且未指定带图方式，可默认带原图，并说明这一假设。
2. **按改进意见修改**：结合原图和用户意见，先整理需要保留与需要修改的具体项，再编辑原图。模糊的视觉要求可转成可执行的字号、布局、配色或层级调整；不擅自新增科学结论。整理后的提示词应可查看和修改；意见足够明确时不额外要求审批。

编辑原图时，未提出修改的内容、公式和关系保持一致，只有指出的错误及必要依赖随之修正。科学错误应纠正并记录原因，不能为相似度保留错误。修改后核对文字、公式、箭头及非目标区域；已有可编辑稿时，以新视觉稿重建受影响元素并同步输出。重生成作为独立新版本验收，不承诺原图布局保真。

## 调用与记录

使用当前工具支持且已核实的 Image 2.5 能力。传参考图或原图前先查看，按工具真实的图片参数传入，本地路径写在提示词里不等于工具读过图片。不要捏造工具参数或将提示词中的模型名称当成调用证明。

保留 `requested_model`、实际工具、`reported_model`、推理设置和实际提示词；工具未返回模型时写为未确认。用户要求锁定模型但环境不支持时，说明具体缺口。不自动改走付费 API 或其他模型。

低推理测试使用同一输入资料、参考图和验收标准，记录实际模型/强度、耗时、返回的 token 用量、成品与缺陷；未返回用量时保持未知。生成质量和可编辑复刻分别检查，若结果不足先说明具体问题，不自动升档，也不把未测试的复杂场景视为通过。

原图和修改后结果另存，保存实际发送的提示词。光栅改图使用图像编辑能力；构建 SVG/PPT 是单独的可编辑复刻步骤。
