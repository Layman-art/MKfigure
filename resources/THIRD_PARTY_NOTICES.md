# Third-party components

MK Figure includes the following open-source components. Their original license files are preserved in the included packages or runtime directories.

- Electron: MIT, with Chromium and other bundled components under their respective licenses. See Electron's LICENSE and LICENSES.chromium.html.
- OpenAI Codex is distributed under Apache-2.0. The platform runtime and its license files are in `resources/codex`. Its manifest identifies the exact official npm package, version and integrity digest.
- PptxGenJS: MIT; https://github.com/gitbrent/PptxGenJS
- React and React DOM: MIT; https://github.com/facebook/react
- JSZip: MIT or GPLv3; used under MIT; https://github.com/Stuk/jszip
- svgpath: MIT; https://github.com/fontello/svgpath
- fast-xml-parser: MIT; https://github.com/NaturalIntelligence/fast-xml-parser
- pdf-parse: MIT; https://gitlab.com/autokent/pdf-parse
- Lucide: ISC; https://github.com/lucide-icons/lucide
- pngjs uses the MIT license. [Project and license](https://github.com/pngjs/pngjs)
- The @jsquash/webp WebAssembly wrapper and wasm-feature-detect use Apache-2.0. The bundled libwebp codec includes Google's BSD 3-Clause license in `@jsquash/webp/codec/LICENSE.codec.md`. [jSquash](https://github.com/jamsinclair/jSquash) · [WebAssembly feature detection](https://github.com/GoogleChromeLabs/wasm-feature-detect)

The llm-for-zotero project inspired the choice of the official Codex App Server integration. Its application code is not included.

The three visual reference images were supplied by the project owner. They are style references, not evidence for generated scientific claims. Proprietary Microsoft font files are not redistributed.

Interface fonts: Inter, Source Serif 4, and Noto Serif SC are distributed under the SIL Open Font License 1.1. Their original notices are included in resources/font-licenses.

The upstream MIT notice, image policy and pinned snapshot record are included in `paper-gallery/`. Paper figures remain the work of their original authors and publishers. Paper and PDF links and full author lists accompany each figure.
