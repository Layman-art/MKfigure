# MK Figure 0.2.1 项目管理更新

更新日期：2026-09-16。Windows 安装文件为 `MK-Figure-0.2.1-Windows-x64-Setup.exe`。

## 使用变化

- 首页保留“新建科研图”和“图片复刻”两个入口。移除离线示例入口、创建路由和生产工作流；示例场景仅作为测试素材保存。已有历史示例项目仍按普通项目读取，不会因升级被删除。
- 首页增加少量静态音符、弧线和曲线节点装饰，小窗减少为一组；装饰不接收点击，并从辅助阅读中隐藏。启动加载完成后直接进入界面，移除品牌动画及固定的 600 + 180 ms 等待。
- “最近的作品”增加独立删除按钮，与打开作品分开操作。点击后由主进程显示系统确认框，默认选择“取消”；确认后调用系统回收站操作。
- 删除范围是所选作品目录，包括内部素材副本、生成图、项目记录及导出在该目录内的文件；不会影响外部原始资料、导出到其他文件夹的文件及其他作品。可通过系统回收站还原。
- 取消确认、回收失败时保留作品；运行中的任务需先停止。删除会等待该作品已排队的保存，后续保存不能重建已删除目录。
