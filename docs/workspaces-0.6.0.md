# 0.6.0 创作工作区

这一版将单图创作、六窗并行和文件夹保存放到同一个工作区。本文说明使用方式与数据边界；最终测试结果和安装包验证另行记录。

## 选择创作方式

- **单图创作**：直接进入一张图的完整流程，依次处理内容与风格、视觉稿、可编辑复刻、检查和导出。已有图片可直接进入复刻。
- **并行创作**：一个桌面窗口内提供六个独立子窗口。宽屏三列两行铺满工作区，小屏调整列数并滚动。每张图有自己的内容、预览、执行按钮、进度及停止操作。

展开一张图时，其余创作实例保持挂载并继续运行；返回总览或首页不会停止它们。六路状态显示在并行页顶部。取消一张只停止对应任务，不自动停止其他图。云端排队、账户额度和限流仍可能影响实际并发与完成时间，六窗不代表保证六倍提速。

单图与并行使用同一套生成、复刻、检查和导出流程。同一作品只能由一个子窗口编辑，避免互相覆盖。顶部可修改作品名称；侧边栏作品项提供打开和确认后移入回收站的操作。

## 用文件夹保存创作

不选文件夹也能开始：**本地作品**继续保存在应用的用户数据目录，升级不迁移或删除已有作品。

点击侧边栏的文件夹按钮或首页“打开文件夹”，选择一个目录。软件会在其中创建专用的 `.mkfigure/`，不扫描或接管目录里的其他文件。新作品随编辑自动保存，侧边栏按当前文件夹列出作品。

```text
研究项目/
└─ .mkfigure/
   ├─ workspace.json       # 工作区标识、统一风格及风格对话
   ├─ style-….png          # 选中的统一参考图副本
   └─ projects/
      └─ 作品标识/
         ├─ project.json  # 内容、阶段、图形、历史与用量记录
         └─ …             # 导入资料副本、生成图及其他项目文件
```

生成图片、可编辑图形、历史版本及导入资料副本随作品保留。原始资料留在原处，不因导入或删除作品而改变。导出到其他位置的 PPTX/SVG/PNG 也不会跟随作品删除；若导出到该作品内部目录，则属于其删除范围。

**当前一个应用实例只有一个活动文件夹**，六个子窗口共用该文件夹。切换前会保存各窗草稿；有生成、复刻或风格优化任务时，需等待完成或停止后再切换。取消选择或重开同一文件夹保留现有状态。

“最近的文件夹”方便再次打开；“返回本地作品”回到原有作品列表。打开新文件夹不会自动把本地作品搬过去，目前不提供跨文件夹搬移作品的界面。

备份、复制或移动创作文件夹时，保留**整个目录，包括 `.mkfigure/`**，之后在新位置重新打开。macOS 等系统可能隐藏点号开头的目录，复制时不要遗漏它。只带走一个导出 PPTX 不等于备份创作记录。

账户登录、全局模型设置及个人素材库仍归应用管理，不作为创作文件夹的一部分携带。所选参考图有独立副本，已有作品不会依赖素材库中那张图始终存在。文件夹功能也不等于云同步或多人同时编辑。

## 统一风格与本图覆盖

点击侧边栏或顶部的“统一风格”，设置当前文件夹的风格描述、配色、背景、线条和参考图片。配色可以填写颜色名称或具体色值。

每张作品有三种选择：

| 选择 | 行为 |
| --- | --- |
| 统一风格 | 下一次生成使用当前文件夹的公共设置。 |
| 本图自定义 | 本图使用自己的描述及参考图，公共调整不覆盖它。 |
| 不用参考风格 | 不附加公共或本图的风格描述与参考图片。 |

中文使用微软雅黑，英文使用 Times New Roman；公式采用衬线数学文字，变量斜体、运算符正体，不使用 Office Math。这些规范不是公共配色变化时可以被覆盖的内容。

任务提交时固定本次采用的风格，之后修改公共设置仅影响后续任务。统一规范有助于一致性，但生成结果仍需在检查阶段核对颜色、字体、布局和科学内容。

参考图从素材库选择，选定后即保存副本；描述、配色等文字编辑通过“保存风格”提交。单图的“内容与风格”是配置入口，视觉稿页通过摘要返回该入口，不要求再次上传同一参考图。

## 可选的 AI 风格助手

可以直接手写风格后生成，无需先调用 AI。需要帮助时：

1. 输入例如“白底，蓝灰配色，细线条，适合英文论文”。
2. 点击“AI 优化风格”，或展开“风格助手”补充意见。
3. 阅读建议，再点击“应用建议”替换描述；不应用则保留原文。

风格建议不会自动触发生图。共享面板中的助手修改当前文件夹风格，本图自定义中的助手只作用于该作品。建议过程会显示耗时、模型和已回传的 token；这些是调用用量，不是账户余额。

## 模型目录刷新

本版内置官方 Codex **0.163.0** 运行时。软件仍通过官方模型目录读取账户可用模型与其推理强度，不把模型名称写死为固定选项。

- 启动、登录后按需获取目录；恢复应用焦点时检查缓存是否过期。
- 应用运行期间每 **6 小时**刷新一次，六个子窗口共享目录缓存。
- “模型与连接”保留手动刷新，并显示更新时间及失败信息。
- 刷新失败保留已有列表；成功也不自动更改用户选中的模型。
- 目录刷新是只读查询，不为刷新而重建正在使用的连接或停止任务。

GPT-6.1 Sol 是否出现以当前客户端和账户返回为准。更新目录不等于升级内置 Codex；更换内置运行时随软件版本更新处理，不在任务中途自动替换。

## 检查和导出边界

结构检查与视觉、科学内容核对仍是不同环节，任务完成不等于成图完全正确。可编辑复刻保留文字和图形对象，复杂公式与图标仍可能需要精修。导出只生成选中的格式：仅选 PPTX 时，只输出一个 PPTX；内部 JSON、原始模型结果与历史保留在项目中。

本版验证脚本包括 `scripts/workspace-ui-smoke.mjs`（桌面 UI、文件夹和布局）及 `scripts/panes-smoke.mjs`（六路并行的隔离与状态）。这些脚本的实际运行结果、在线模型范围与平台安装包验证以最终验证记录为准。
