# 0.5.1 同一窗口内的五路并行创作

本版纠正 0.5.0 的理解偏差：仅有一个原生桌面窗口，窗口内提供五个独立创作子窗口，不再弹出五个桌面窗口。

每个子窗口可新建或上传图片，单独填写主题、风格要求和参考图，选择生成或复刻后开始；也可用顶部按钮开始所有就绪任务。五个任务状态始终可见。展开一个子窗口时，其余工作实例保持挂载并继续运行；返回总览不丢草稿或任务状态。停止只作用于对应作品。

模型、连接与素材库共享，作品、图像、风格与任务状态独立。正在运行时不允许修改全局模型配置。同一作品只归一个子窗口编辑，避免覆盖。退出前由主界面汇总五份待保存内容，保存失败保留窗口；关闭时有任务运行会询问是否停止全部任务。

## 实现

- Renderer `WorkspaceShell` 固定挂载五个 `App`，使用稳定 key，紧凑总览和展开模式共用同一个实例。
- Preload 提供五个 scoped API，IPC 请求包含 `{paneId,args}`。主进程只接受唯一主窗口主 frame 的请求，验证 paneId 只能为 1–5。
- `WorkspaceRegistry` 按子窗口管理作品归属，运行、保存、导入和切换按 pane 隔离。进度事件包含 paneId，前端按 pane 过滤。
- 模型任务沿用每次独立 RPC 和临时目录，保持图像文件、输出、用量及取消隔离。并发不代表本机 GPU 执行云端模型。

## 验收

138 项单测通过，2 项在线测试跳过。Windows 打包版在 1440×900 下五张卡片和开始按钮全部同屏可见，960 宽度下采用两列滚动并固定显示五路状态。展开页提供“子窗口首页”，可以切换历史作品。

- `scripts/panes-smoke.mjs` 使用真实 Electron、Store、Workflow 和 IPC，模型服务采用本地同步屏障，验证一个原生窗口、五个可见卡片、五个请求同时进入、独立风格/结果/进度、取消一路其余四路继续、展开不卸载其他实例、迟到终态不恢复 busy、全局设置同步，以及五份草稿的关闭保存和失败保留。
- `scripts/panes-desktop-smoke.mjs` 使用生产入口检查五卡与一个原生窗口、上传图片/风格保存、展开/收起、小窗口布局、单实例，以及原生 PPT/SVG/PNG 导出。
- 五路并发为本地测试服务验证，未额外发起五张线上生图。真实服务并发和完成时间仍受账户配额、服务排队和限流影响，不能承诺五倍提速。

Mac 安装包仅完成封装/结构验证，不等于真实 Mac 并行操作验证。0.5.0 的原生多窗口入口已经从本版源码移除。

本次产物为 `release/MK-Figure-0.5.1-Windows-x64-Setup.exe` 与 `release-mac/MK-Figure-0.5.1-macOS-{arm64,x64}.zip`。界面截图与测试记录位于 `output/panes/0.5.1/`。总览截图中的图片来自隔离测试时上传的内置素材，不作为新的 AI 生成结果展示。
