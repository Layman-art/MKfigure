# 0.3.0 图片素材库

首页第三个入口改为“图片素材库”。参考图与图标集中存放在完整页面中，支持分类、搜索和大图查看。绘图表单仅显示当前参考名称及“从素材库选择”，取消原有内嵌图集和预览区重复的参考小图。

## 使用方式

1. 从首页进入素材库，或在作品的“风格参考”中打开。
2. 可选内置素材，也可按“参考图 / 图标”分类批量导入 PNG、JPEG、WebP、SVG。
3. 在作品中点击“用作风格”，返回原来的创作步骤；已输入文字和手写风格要求保留。
4. 打开素材详情可导出原文件。个人素材还能改名、改分类、删除；删除确认默认取消，确认后进入系统回收站。

内置 13 项：既有 3 张参考图，加上之前“复刻图片并导出 SVG”任务中的 10 个独立城市防灾图标。图标含通信基站、输电铁塔、三个人物、应急发电车、电动汽车、移动储能、无人载具、台风。目录见 `resources/library/catalog.json`，原 SVG 与用户原件的 SHA-256 一致。

个人素材原件和缓存预览在应用用户数据目录的 `library` 中持久化。导入采用复制，外部文件保持原状；改名和分类只影响库内记录。SVG 的 PNG 预览使用白底，导出 SVG 保留原本的透明背景、路径与可编辑性。

选作参考时，应用给作品另存 PNG 副本；之后库中素材被改名或删除，该作品仍使用自己的副本。旧项目的内置风格 ID 和自定义参考兼容。素材库不自动把图标插入已重建的 PPT 图形。

## 实现与验证

- Renderer 仅通过显式 preload API 访问素材。主进程负责文件对话框、路径校验、原件导出和回收操作。
- SVG 仅接受静态矢量内容，拒绝脚本、外部资源与动态标签；SVG 原件不作内容改写。
- PNG/JPEG 直接解码；WebP 使用受限 Chromium 解码；SVG 长数据在导航后载入，避免大图预览触发 URL 长度错误。
- 导出目标解析真实父目录，避免目录链接把原件写回内部素材库；内置素材只读。
- `npm test`：112 项通过，2 项在线测试跳过。素材库新增 32 项测试。
- 严格 TypeScript 检查通过，包括未使用变量/参数检查。
- `scripts/library-smoke.mjs` 在真实 Electron 与独立数据目录中验收：13 项内置素材、4 种格式导入、无效 SVG 拒绝、改名分类、原 SVG 字节一致、参考选择与阶段返回、删除后的作品副本、取消导入/删除、重启后持久化、导出目录链接保护，以及 1440 / 960 窗口布局。
- `scripts/smoke-electron.mjs` 验证原有 PPTX/SVG/PNG 导出；只勾选 PPTX 仍只产生一个 PPTX 文件，界面无脚本错误。

界面测试中的系统文件对话框和回收动作使用隔离测试替身，不操作真实用户素材；真实 Chromium 解码、渲染、IPC 和磁盘持久化均有执行。本轮不调用在线模型，不消耗生图/复刻额度；也未重新进行 PowerPoint 实机编辑验收。

截图与验收记录位于 `output/playwright/library-0.3.0/`，安装包中的对应记录位于 `output/playwright/library-0.3.0-packaged/`。Windows 打包与 Mac 资源校验沿用项目发布流程；Mac 包未在真实 Mac 上运行，也未做 Developer ID 签名或 Apple 公证。
