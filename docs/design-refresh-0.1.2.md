# MK Figure 0.1.2 界面调整

2026-09-16。最终版本包含用户追加的图标质感与文案精简要求。

## 已完成

- 新图标为陶土色折纸 M、象牙色底板和柔和接触阴影。使用内置 imagegen 生成，源图保存在 `resources/icon-source.png`，提示词见 `output/design-refresh/icon-generation.md`。PNG、Windows ICO、macOS ICNS 与界面品牌图统一来源。
- 页面采用暖纸色，标题与正文分层；正文 15px，常用标签与按钮 14px。窗口尊重系统缩放，预览区域完整容纳图片，表单独立滚动，弹窗操作栏固定可见。
- 首页入口精简为“新建科研图 / 图片复刻 / 离线示例”。删除重复英文眉标题、STUDIO、口号、流程页脚、卖点与重复提示，缩短表单、设置和导出说明。
- 将设置、文字编辑、参考图选择和公共控件拆出 App；删除确认无用的状态、参数、分支、类型导入与 zod 依赖。自动保存、模型操作、导入及导出的核心流程保留。
- 字体仅保留界面使用的子集和字重，改为构建依赖，许可证随包分发。干净构建目录内字体资源为 204 个文件、7,454,348 字节，原检查值约 22.17 MiB。
- 缩短启动展示等待；图形导出尺寸保持独立于显示缩放。科研图原有字体和公式组件规则保留。

组件拆分主要改善维护性，不计为净删代码。CSS 补齐了原先缺失的预览、检查、导出和弹窗样式，因此不以文件字节数减少衡量这部分工作。

## 验证

- TypeScript 与未使用声明检查通过。
- 单元测试 36 项通过，2 项在线测试按配置跳过；本轮没有重跑收费的在线生图流程。
- 最终 Windows 打包程序通过离线桌面 smoke：3 张参考图、自定义图导入、直接复刻入口、94 元素示例、PPTX/SVG/PNG 导出、密钥加密保存和非法路径防护。
- 最终包截取 14 个界面状态，覆盖 1440×900、1280×800、1040×720、960×640；页面与面板无横向溢出，预览图加载且完整包含，页面错误为 0。设置滚动后保存按钮可点击，文字编辑及放大预览可打开。
- 调整缩放后另测 100% 和 200% 显示比例，1200×640 场景的输出 PNG 仍为 1200×640。最终截图来自当前系统的 150% 显示比例。
- Windows 安装器已构建，打包程序已运行；没有替用户执行系统安装。
- macOS arm64/x64 ZIP 已完成架构、符号链接、资源、图标、ASAR、Codex 哈希和 CRC 校验。仅 ad-hoc 签名，未进行真实 Mac 运行验收或 Apple 公证。
